O que é MEMORABILIA
Um pipeline audiovisual self-hosted que automatiza o trabalho repetitivo e acumula memória entre projetos. O designer que trabalhava 3 dias trabalha 1.

Tradução de tempo

Cada agente não processa footage — traduz. Vídeo em áudio, áudio em texto buscável, footage em frames navegáveis, material bruto em observações narrativas. Nenhum agente decide. Todos traduzem. O designer decide.

Memória projetual

O Agent 3c lê com dupla perspectiva (livros + projetos). O Agent 8 deposita cada decisão com contexto. O projeto 10 é mais preciso que o projeto 1 — porque acumulou 9 projetos de decisões reais.

Privacidade total

3 GPUs · 38GB VRAM · 208GB RAM · 20TB storage. Tudo em hardware próprio. Nenhum dado sai da rede. VPN criptografada para acesso global. Custo mensal: zero.

Colaborativo por design

Novos nós expandem o cluster via VPN sem expor dados. Ilustradores, motion designers e editores acessam a mesma memória projetual, cada um no domínio relevante.

CEP Panel — Second Brain no Premiere
Extensão que roda ao lado da timeline. 3 views sobre o mesmo material. Busca = criação.
L
List View
Texto compacto com transcrição inline
▸

Linha compacta com thumbnail, timecode, transcrição e score. Drag handle para reordenar por swap. Ideal para escanear resultados rapidamente.

G
Grid View
Thumbnails arrastáveis lado a lado
▸

Thumbnails com frame real. Click para selecionar, drag para reordenar por swap. Badges com score e timecode. Ideal para explorar visualmente.

⬡
Graph View — Estilo Obsidian
Grafo relacional force-directed com thumbnails reais
NOVO▸

Cada clip é um nó circular com a imagem real do frame. Temas extraídos automaticamente (sunset, crowd, medium shot) aparecem como nós menores pastel conectando clips relacionados. SVG com 4 layers: edges → themes → clip-bg → clips.

Sidebar esquerda (estilo Obsidian): Filters (toggles Temas/Links/Órfãos) · Groups (@tag) · Display (sliders text fade/node size/link thickness) · Forces (sliders center/repel/link/distance)

Sidebar direita (clip info): Thumbnail · timecode · score · auto_tags · descrição visual · transcrição Whisper · observação Agent 3c. 4 botões: Open in Source Monitor · Go to TC · + Marker · Copy TC

Interação: Zoom (scroll wheel centrado no cursor, 20%-500%) · Pan (Shift+drag ou middle-click) · Drag nodes (click=select, drag=move, threshold 3px)

Busca = criação: #tag filtra ou cria · !select marca bookmark · @clip filtra por links

Design Philosophy — 7 Princípios
O sistema como produtor de história. Cada princípio tem um teste que valida a implementação.
1
Tradução de Tempo
O agent transforma ou apenas copia?
2
Anti-Biblioteca
O output é encontrável por significado?
3
Desdobramento em Camadas
O output gera múltiplas camadas de valor?
4
Contexto Relacional
O output carrega relação com o resto?
5
Amplificação
O output navega ou prescreve?
6
Paralelismo
O agent declara dependências e roda quando pode?
7
Julgamento Acumulado
O agent deposita algo que calibra o futuro?

Inspiração: entrevista Andrea Trabuko (Pentagram) — o designer como produtor de história, a anti-biblioteca como sistema de acesso, o repertório como diferencial intransferível.
